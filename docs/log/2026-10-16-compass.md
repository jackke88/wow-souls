# Native quest return compass

User request: add an Elden Ring style compass and show where to run to hand in completed quests. This continues the approved native UI; the map and original overhead !/? models are unchanged.

## Behavior

- A thin, fading gold rule is anchored at the top center in the shared 720p logical layout. Small ticks, serif N/E/S/W and an ivory center diamond move with the actual camera heading. Text uses centered parent containers; cardinal text and its shadow fade together at the edges.
- Small **?** signs point toward the end NPCs of completed, unsubmitted quests. The caption identifies the focused NPC and rounded ground distance in WoW yards. Looking toward a destination focuses it; otherwise the closest return is named. Within the existing talk radius the caption becomes **Ready to return** and the sign stays at the center.
- Goals outside the front semicircle remain visible at an edge with a left/right turn arrow, including goals behind the camera. Angle wrapping stays correct across north/360 degrees. A vertical camera reuses the last valid heading.
- Close bearings share a sign and a centered badge counting completed quests. The nearest destination leads a group. Multiple completed quests for one NPC produce one destination; duplicate spawn sites choose one nearest location. Loaded NPC positions are used where available.
- A quest disappears when it is rewarded or abandoned. Incomplete and new quests add no compass markers. Missing/unknown NPC sites do not produce fake locations. The compass hides for inventory, dialogue, system menus, the map and death, and is cleaned up on leaving gameplay.

This is direct bearing guidance, not obstacle/path routing. No new input, interaction, save schema, quest behavior or camera control was added. Original overhead signs keep their M2 paths, yellow/grey colors, scale and spin/bob.

## Implementation and reuse

`crates/wow-souls/src/hud/compass.rs` owns the passive UI and lifecycle; `hud/compass/nav.rs` owns quest destination extraction, heading math, nearest-site selection, projection, grouping and focus. Only the HUD module registration changes outside those files. Quest-derived destinations are cached until completed ids change; camera/player/live-NPC geometry updates each visible frame, with unchanged UI values left alone.

The compass uses the existing Georgia font, UI palette and native line/gradient/shadow rendering. There are **zero generated images, new art files, dependencies, API calls or runtime API costs**. The same code works with other world manifests. No installed assets are exported. `WOWSOULS_COMPASS=0` hides the compass; `WOWSOULS_COMPASS_TRACE=1` records headings and NPC bearings/edge/distance once per second. README documents both.
