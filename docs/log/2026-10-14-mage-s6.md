# Mage S6: the trainer by class, the docs (2026-10-14)

Built by `docs/superpowers/plans/2026-10-14-mage-class.md` Task 6.

- `shop::services(data, flags, entry, class)`: a trainer is offered only to the class whose row names it (`wow_world::class::trainer_of`); `quests/mod.rs` passes `g.player.class as u8`.
- `shop::attempt` `Request::Train`: the lesson must be on `abilities::trainer_list(c.npc)`, so a forged request for another class's spell (or at an NPC that is no trainer) is `NotYet`, nothing spent.
- README: the Mage paragraph, `WOWSOULS_MANA` in the switch table.
- Verified live: a level 4 mage at Khelden Bremen with 400 souls learns Frostbolt (`shop: You have learned Frostbolt for 400 souls.`), a second press says "You already know that.", the save holds `learn 116`, the bar shows three icons.
- What the user should judge when playing: the cast length in a Souls fight, the mana pool and its trickle, the clip picks (Frost Armor's `a00_6217`), Frost Armor's crystal over the head, how fast a level 1 mage (52 health) dies to a kobold (two blows).
