## What was built for the spiders (files, exact)

**dsr-cache (`crates/dsr-cache/src`)**
- `bonemap.rs`: `Pair.rel` + `const fn pr(...)` = **pose-relative pair**: the DS bone's rotation change from the clip's FIRST frame applied to the WoW bind pose, no bind alignment (the DS crag spider's bind is a T-pose, so bind-relative mapping drifted 26–63° and lifted the body 1.3 yd). `CRAG_SPIDER: DsNames` (forearm = `Tail1`, so the strike volume runs head → forward, not head → thorax). `MINESPIDER`/`TARANTULA` pair tables + `*_RIG`: hips = second leg pair (`LLeg_e1`/`RLeg_e1`), **no sole checks, no ground lock** (the legs rotate with the DS deltas but their geometry differs, so any foot gate fails; judged visually instead).
- `retarget.rs`: `relative = pairs.any(rel)` → `reference` = DS model space at frame 0 for pairs, pelvis and cross checks; `hip_origin` puts the hip-joint midpoint at the WoW bind position and moves it by the DS hip change. Non-relative rigs are unchanged (bind used).
- `monster.rs`: `Lying.pelvis` field (was hard-coded 0.6; spiders 0.85), `LYING_SPIDER` (body 2.5, settle 0.6: dies on its back with legs up), `LYING_TARANTULA` (body 12). New `Tier::Skirmish` (max 3 attacks: two blows + a hop with no blow). `MINESPIDER_KIT` attacks: `bite` `a00_3000` (judge 100), `leap` `a00_3001` (judge 110, window from DS 0.70–0.87, rewritten by the bake), `hop_back` `a00_3500` (judge 110, window `(9.0, 9.1)` = never strikes). `Leap`/`LEAP_MINE {travel 2.6, arc 1.3}`/`LEAP_TARANTULA {travel 3.0, arc 2.2}`/`leap_of(kit)`/`bake_leap(clip, hit, leap)`: crouch, then smoothstep travel and half-sine arc over the flight (launch = window start − 0.25 s, land = window end + 0.20 s), hit window becomes the flight (0.50–0.97 s); one unit test. `reference_dir` `minespider_ds`/`tarantula_ds` for `WOWSOULS_DSVIEW`.
