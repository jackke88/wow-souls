# Mage S2: a Mage can be made and plays with a mana bar (2026-10-14)

Built by `docs/superpowers/plans/2026-10-14-mage-class.md` Task 2.

- `Character::max_mana` = `basemana` + Intellect's mana (20 + 15 per point above 20), only for a class whose table has mana: a human mage at level 1 has **165** mana and **52** health (the warrior stays 60 / 0).
- `wow_world::quest::{Class::from_id, Player::of_class}`; `quests::load` builds the quest game's player from the chosen character's class (it was `Player::warrior` always), so the class tables, class quest masks and the hotbar follow the creation menu.
- `Class::enabled` lets Warrior and Mage through.
- Game: `abilities::Mana { cur, max, quiet, spirit }` (`sync`, `spend`, `tick`, `refill`; the five-second rule, 0.07 mana/s per Spirit; gear-off / gear-on is neither a loss nor a free refill), `ActiveClass`, `activate` over two powers, `Refusal::NotEnough(Power)`, rage gained only by a class that has rage, a new life refills mana, `WOWSOULS_MANA=<n>`.
- HUD: the thin bar under stamina is blue and follows mana for a mage (`ui::bar_of`); the slots dim by the class's power.
- `level::follow_level` syncs the pool every frame from the tables and the gear.
- Live: see the ledger line (kit, 52 HP, screenshot with the blue bar).
