## Superseded first attempt

**Goal:** implement the user's approved class-emblem design for health, class power (mana OR rage), stamina and XP. This is the first part of the requested UI overhaul.

**Architecture:** an original generated transparent atlas supplies only frames/class emblems. A new `hud/vitals.rs` draws clipped procedural fill textures and native dynamic text over it, using the real `Health`, `Stamina`, `ActiveClass`, `Mana`, `Rage` and `QuestGame` values. It reuses the existing damage-chip and XP-glide logic. The status group is anchored in the top-left in the existing 1280x720 layout space and scales with the window; fixed track widths encode current/max through fill and numbers. Other HUD elements remain as they are. New status art/text must work without the DSR HUD cache.

**Tech Stack:** Rust, Bevy 0.18.1 UI, embedded PNG decoded with the existing `png` dependency, existing project fonts, built-in screenshots/video recorder.

## Approved visual direction

The user chose **"Bygg in förslaget med klass-emblem"** after seeing `docs/evidence/ui-vitals/concept-v1.png`: weathered bronze/iron frames, Mage staff / Warrior swords medallions, level badge, crimson health, sapphire mana or ember rage, green stamina, thin amethyst XP. The original concept and exact built-in imagegen prompts are retained. All numbers and labels are rendered by the game, never baked into the PNG. No game-install images are copied into these new assets.
